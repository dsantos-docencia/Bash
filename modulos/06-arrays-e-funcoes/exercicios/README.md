# 🏋️ Exercícios — Módulo 06

Corrija com `./ferramentas/corrigir.sh 06`. Soluções em [solucoes/](solucoes/).

### 01 — Média · `01-media.sh`
Recebe N números como argumentos e imprime a **média inteira** (divisão inteira). Ex.: `bash 01-media.sh 10 20 30` → `20`. Use uma função `local` para somar.

### 02 — Maior elemento · `02-maior.sh`
Recebe N números como argumentos e imprime o **maior**. Ex.: `bash 02-maior.sh 3 9 2 7` → `9`.

### 03 — Contar vogais · `03-contar-vogais.sh`
Recebe uma palavra em `$1` e imprime quantas vogais (a,e,i,o,u, minúsculas) ela tem, usando um **array associativo** como contador OU um laço sobre os caracteres. Ex.: `bash 03-contar-vogais.sh programacao` → `5`.
