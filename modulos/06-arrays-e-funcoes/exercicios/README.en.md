# 🏋️ Exercises — Module 06

**🌍 Idioma / Language:** [Português](README.md) · **English**

Grade with `./ferramentas/corrigir.sh 06`. Solutions in [solucoes/](solucoes/).

### 01 — Average · `01-media.sh`
Receives N numbers as arguments and prints the **integer average** (integer division). E.g.: `bash 01-media.sh 10 20 30` → `20`. Use a `local` function to sum.

### 02 — Largest element · `02-maior.sh`
Receives N numbers as arguments and prints the **largest**. E.g.: `bash 02-maior.sh 3 9 2 7` → `9`.

### 03 — Count vowels · `03-contar-vogais.sh`
Receives a word in `$1` and prints how many vowels (a,e,i,o,u, lowercase) it has, using an **associative array** as a counter OR a loop over the characters. E.g.: `bash 03-contar-vogais.sh programacao` → `5`.
