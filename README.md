# Bash

Bash (Bourne Again SHell) é um shell de linha de comando e linguagem de
script. Este repositório é um guia de estudo com conceitos, exemplos, dicas e
documentação para quem está começando ou quer aprofundar seus conhecimentos.

[Português](#português) · [English](#english)

## Português

Este repositório reúne materiais para aprender e consultar Bash. É aberto a
alunos, entusiastas, professores, profissionais e qualquer pessoa interessada
em shells e automação.

### Roteiro de estudo

Os materiais podem ser organizados progressivamente nestes tópicos:

1. **Fundamentos** — terminal, comandos, variáveis, aspas e expansão.
2. **Scripts** — shebang, argumentos, entrada e saída, códigos de retorno.
3. **Controle de fluxo** — condições, loops, funções e `case`.
4. **Texto e arquivos** — redirecionamentos, pipes, `grep`, `sed`, `awk` e
   manipulação de arquivos.
5. **Boas práticas** — tratamento de erros, depuração, portabilidade e
   segurança.
6. **Exemplos e dicas** — receitas curtas para tarefas do dia a dia.

### Como usar os exemplos

Leia os comentários e requisitos antes de executar qualquer script. Confira
com atenção os comandos que alteram ou removem arquivos, e teste exemplos em
um diretório temporário quando possível. Os exemplos devem indicar dependências
externas e versões de Bash quando isso for relevante.

### Contribuições

Contribuições são bem-vindas. Prefira exemplos pequenos, explique o que fazem
e inclua os requisitos necessários para executá-los. Mantenha a linguagem
acessível e, quando possível, forneça a documentação em português e inglês.

## English

Bash (Bourne Again SHell) is a command-line shell and scripting language. This
repository is a study and reference guide with concepts, examples, tips, and
documentation. It is for students, enthusiasts, teachers, professionals, and
anyone interested in shells and automation.

### Learning path

Materials can be organized progressively around these topics:

1. **Fundamentals** — the terminal, commands, variables, quoting, and
   expansions.
2. **Scripts** — shebangs, arguments, input and output, and exit statuses.
3. **Flow control** — conditionals, loops, functions, and `case`.
4. **Text and files** — redirections, pipes, `grep`, `sed`, `awk`, and file
   operations.
5. **Good practices** — error handling, debugging, portability, and security.
6. **Examples and tips** — short recipes for everyday tasks.

### Using the examples

Read comments and requirements before running any script. Carefully review
commands that modify or remove files, and use a temporary directory for testing
when possible. Examples should state external dependencies and Bash versions
when relevant.

### Contributing

Contributions are welcome. Keep examples small, explain what they do, and
include any requirements needed to run them. Keep the material approachable
and, whenever possible, provide documentation in both Portuguese and English.
