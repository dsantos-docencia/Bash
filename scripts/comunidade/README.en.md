# 🌱 Community scripts

**🌍 Idioma / Language:** [Português](README.md) · **English**

This folder is a **collaborative catalog**: useful scripts submitted by people in the community, curated and credited.

> **Want to submit yours?** Open an issue via the **"📜 Submit a script to the community"** track ([new issue](https://github.com/dsantos-docencia/Bash/issues/new/choose)). We review it, comment, and, if it makes sense, include it here with your credit. *Don't let the knowledge die with you.*

## How the curation works

1. You submit the script (issue or PR) and tell us what problem it solves.
2. We review it together: clarity, safety (no surprise destructive effects), and whether it passes ShellCheck.
3. We adjust whatever is needed — always keeping **your credit as the author**.
4. It lands here, with a standard header and a line in the index below.

## A community script's standard

Each script carries a header like this:

```bash
#!/usr/bin/env bash
# ============================================================================
#  Community script · <name>
#  Author: <Your Name> (@your-user)
#  Curation: Prof. Daniel Santos' Bash repository
#  License: PolyForm Noncommercial 1.0.0 (noncommercial use) — see /NOTICE.md
#  What it does: <one line>
# ============================================================================
```
